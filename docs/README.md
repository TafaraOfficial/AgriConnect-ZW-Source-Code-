## Project implementation overview

The working application in this repository provides a functional marketplace for agricultural trading with user authentication, listings, and order handling. The academic files remain available alongside the implementation so the project can be used both for a practical working demo and for coursework documentation.

## Developer notes

- The actual application code is located in the `app/` folder and started via `app.py`.
- The project is designed to run locally using SQLite and Flask.
- The academic documents should be preserved and updated as needed for assignment submissions.
